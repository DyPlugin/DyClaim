# DyClaim 1.1.0

## Added

- **Claim limits by permission.** `dyclaim.limit.<number>` and `dyclaim.limit.unlimited` replace the default `claim.max-claims-per-player` for a player or group; the highest one wins. `/claim list` and PlaceholderAPI show the effective limit. Switch: `claim.permission-limits.enabled`.
- **Claim messages.** `/claim message <text>` sets a line that visitors see when they walk into the claim; `/claim message clear` removes it. Length and colour codes are configurable. Permission `dyclaim.message`, switch `claim-messages.enabled`.
- **Visitor bans.** `/claim ban <player> [duration]`, `/claim unban <player>` and `/claim banlist` keep a player out of one claim, permanently or for a time. A banned player inside the claim is moved to a safe spot outside. Owners, coowners, admins and `dyclaim.ban.exempt` cannot be banned. Permission `dyclaim.ban`, switch `claim-entry-bans.enabled`.
- **PlaceholderAPI.** The built-in `dyclaim` expansion provides claims, limit, remaining, owner, claim name, role, PvP and build placeholders. No eCloud download is needed. Switch: `integrations.placeholderapi.enabled`.
- **Web maps.** Claims are drawn on BlueMap, Dynmap and squaremap. Each owner's neighbouring chunks are joined into a few areas with one stable colour. Refresh interval, layer name, opacity and hidden worlds are configurable. Each map has its own switch under `integrations.maps`.
- **Import from GriefPrevention and ClaimChunk.** `/dyclaim admin import griefprevention|claimchunk` shows a preview; adding `confirm` copies the claims and their trust after a backup. The source data is never changed and the command is safe to run again.
- **Developer API.** `dev.dyclaim.api.DyClaimAPI` reads claims, limits and build access. `ClaimCreateEvent`, `ClaimRemoveEvent`, `ClaimTransferEvent` and `ClaimTrustChangeEvent` report changes. See [the API guide](../api.md).
- **German, Spanish and Russian messages.** `lang: auto` selects them from the Minecraft client language. `/claim lang de|es|ru` and `/claim admin lang de|es|ru` select them directly.
- **MiniMessage.** On Paper, Purpur and Folia, messages may use MiniMessage tags such as `<green>` or `<gradient:#55ff55:#55ffff>` next to `&` codes. Adventure is not bundled, so on Spigot only `&` codes apply. Player names, claim names and other inserted values are never read as tags. A claim message's tags apply only with `claim-messages.allow-colors: true`.
- **bStats statistics** (plugin ID 34849): anonymous server count and a few DyClaim charts. Turn it off with `metrics.enabled: false`.
- `/claim admin diagnose` now lists active PlaceholderAPI and map hooks.

## Changed

- Ownership transfers and market sales also clear the old owner's claim message and visitor bans.
- Trusting a banned player lifts their ban; banning a trusted player removes their trust.
- Diagnostics shows Floodgate with its correct plugin name.
- Claim changes other than purchases (trust, settings, names, messages, bans) are written to disk in the background, so large claim files no longer pause the server. Steps that involve money, imports, inactive cleanup and shutdown still save immediately.

## Upgrading

Back up the existing JAR and the complete `plugins/DyClaim` directory, stop the server, and replace the JAR with **one** 1.1.0 backend (`DyClaim-1.1.0.jar`, or `DyClaim-1.1.0-Folia.jar` on Folia). Keep the data directory.

- Claim data, configuration, commands, aliases and custom messages are retained. New settings are added with their defaults.
- The new player features (claim messages and visitor bans) are on by default. Turn them off with `claim-messages.enabled: false` and `claim-entry-bans.enabled: false`, or remove `dyclaim.message` and `dyclaim.ban` from players.
- Players without any `dyclaim.limit.*` permission keep the old limit.
- Use `/dyclaim` for the import command while GriefPrevention is installed, because GriefPrevention also registers `/claim`.

See [integrations](../integrations.md) and the [verification evidence](../verification-1.1.0.md).
