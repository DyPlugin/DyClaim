# DyClaim 1.3.1

A developer write API so estate and economy plugins can sell, rent and lease claims, and lighter protection checks. Nothing changes in how claims behave for players or server owners.

## Added

- **Developer write API for estate and economy plugins.** `DyClaimAPI` gains five methods:
  - `getClaimById(UUID)` finds a claim by its id.
  - `transferClaim(UUID claimId, UUID newOwner, String newOwnerName)` gives a claim to another player, who may be offline. Like `/claim transfer`, the coowner, trust, market price, claim message and visitor bans are cleared. Fires `ClaimTransferEvent`.
  - `setTrust(UUID claimId, UUID player, Set<String> rights, long expiresAt)` grants or replaces a player's trust with exactly the given rights (the `/claim trustperm` names). `expiresAt` is epoch milliseconds, `0` is permanent. Fires `ClaimTrustChangeEvent`.
  - `removeTrust(UUID claimId, UUID player)` ends a player's trust. Fires `ClaimTrustChangeEvent`.
  - `getTrustRights(UUID claimId, UUID player)` returns the rights of a player's active trust.
- The write methods can be called from any thread. On Folia, call them on the region thread that owns the claim's chunk so they stay in order with players' own changes. `transferClaim` refuses server claims and claims locked by a running DyClaim payment; `setTrust` refuses the owner, the coowner, unknown or empty rights and a past expiry.

## Changed

- Claims are also indexed by id, so lookups by id do not scan the claim list.
- **Lighter protection checks.** Block, interaction, explosion, fluid and movement checks find the claim from block coordinates instead of building a chunk object on every event. The claim's own answer (owner, coowner, trust) now comes before the `dyclaim.admin.bypass` permission check, so owners and trusted players are allowed without any permission lookup; every check gives the same result as before. Claim owners, coowners and trust are read without taking a lock.
- **Denial messages are built once.** The finished, coloured text of messages without placeholders is kept per language until `/claim reload` or a prefix change. On Paper, Purpur and Folia, protection denials go to players as a ready component instead of text the server parses again on every event. Spigot, messages with line breaks or web addresses, and messages with placeholders work as before. No message text changes.

## Fixed

- Nothing in this release.

## Upgrading

Stop the server, replace the old JAR with `DyClaim-1.3.1.jar` and start the server. No settings, messages or claim data change. Plugins built against 1.3.0 keep working.
