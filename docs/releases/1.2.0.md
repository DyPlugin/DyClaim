# DyClaim 1.2.0

One JAR now serves Bukkit, Spigot, Paper, Purpur and Folia. This release also adds server claims, trust for whole permission groups and glowing display borders. Existing commands, settings and claim data are kept.

## Added

- **One JAR for every server.** DyClaim detects Folia at startup and uses its schedulers there. Servers on the 1.1.0 Folia build can install `DyClaim-1.2.0.jar`.
- **Server claims.** `/claim admin server` (Turkish `/claim admin sunucu`) protects the chunk you stand in for the server. It has no owner, price or claim limit, and only holders of `dyclaim.admin.serverclaims` manage it. `/claim admin server remove` lifts it. A chunk owned by a player is never turned into a server claim.
- **Group trust.** `/claim trust group:<name> [duration]` trusts everyone who has `group.<name>`, which is how LuckPerms marks group members. Untrust and the trust list work the same way. Turn it off with `integrations.permission-groups.enabled: false`.
- **Display borders.** `/claim see` draws glowing lines that only the viewer can see, on Minecraft 1.19.4 and newer clients. Settings: `visualization.style` (`display` or `particles`), `display-block` and `display-glow`. Bedrock players keep the block border.

## Upgrading

Stop the server, back up `plugins/DyClaim`, replace the old JAR with `DyClaim-1.2.0.jar` and start the server. New settings are added with their defaults. Claim data and translations are kept, and new messages are added in every language.
