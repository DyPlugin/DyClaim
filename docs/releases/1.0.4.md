# DyClaim 1.0.4

## Added

- Paged help. `/claim help [page]` and `/claim admin help [page]` show eight commands per page with the exact command for the next page. The console still receives the complete list.
- `/dyc` as a short form of `/claim`, for example `/dyc list`.
- `/cltp <number|name>` as a short form of `/claim tp`. It is listed in English and Turkish help and is available to every player with `dyclaim.teleport` (granted to everyone by default).
- `/dyca` as a short form of `/claim admin`, for example `/dyca reload`. It requires `dyclaim.admin`, so players without that permission do not see it in TAB or help.
- TAB suggestions for help page numbers.

## Changed

- English and Turkish messages were rewritten to be shorter and clearer. Turkish now uses one consistent form of address and no longer mixes in English words such as "trust".
- Message texts that a server never edited are upgraded to the new wording automatically, including on servers upgrading from Beta through 1.0.3. Edited texts are always kept, and existing message files are not rewritten.
- Turkish confirmation hints now point to `/onayla` and `/reddet`. `/confirm` and `/cancel` continue to work.

## Fixed

- Players without permission for coowner, transfer, market or warning commands received both "no permission" and "feature is turned off". They now only see the permission message.
- `/cancel` (`/reddet`) repeated the "[Cancel]" button label as a chat message. It now confirms that the action was cancelled and nothing changed.
- `/claim admin diagnose` no longer falls back to a hard-coded old version number when the plugin description is unavailable.

## Upgrading

Back up the existing JAR and the complete `plugins/DyClaim` directory, stop the server, and replace the JAR with **one** 1.0.4 backend (`DyClaim-1.0.4.jar`, or `DyClaim-1.0.4-Folia.jar` on Folia). Keep the data directory. Claim data, configuration, commands, aliases and custom messages are retained.

See [verification evidence](../verification-1.0.4.md) for what was tested.
